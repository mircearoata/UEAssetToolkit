# Unreal Engine Asset Toolkit

A set of 2 plugins, one for generating asset dumps from the game and second for making assets from them in editor

## Usage

To use these plugins, see the
['Unreal Engine Asset Toolkit' page on the Satisfactory Modding Documentation](https://docs-dev.ficsit.app/satisfactory-modding/latest/CommunityResources/AssetToolkit.html).

Note that the dev version of the docs are linked above
as there are frequently community changes to the asset toolkit and its usage directions
that are slow to merge.
